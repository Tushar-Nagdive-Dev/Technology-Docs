
## 🧭 Phase 1: Getting Started – Computer Fundamentals

Before jumping into Java, let’s build your foundational understanding of computers and how programming fits into the bigger picture.

### ✅ Module 1: Understanding Computers

#### 🎯 Learning Goals:

* What is a computer?
* Basic components (hardware + software)
* Types of computers
* How data is stored and processed

#### 🧠 Topics Covered:

1. **Definition of a Computer**
2. **Input, Process, Output (IPO Model)**
3. **Basic Hardware Components**:

   * CPU, RAM, Hard Disk, Motherboard, I/O Devices
4. **Software Types**:

   * System Software (e.g., Operating Systems)
   * Application Software (e.g., Word, Browser)
5. **Data & File Storage Basics**
6. **Binary, Decimal, and Hexadecimal Numbers**

#### 🛠️ Exercise:

* Label parts of a computer (diagram)
* Convert decimal to binary and binary to decimal

#### 🧩 Real-World Example:

Your smartphone is a computer. It processes your input (touches), runs apps (software), stores photos (data), and gives output (display).

## 🚀 Phase 2: Introduction to Programming

Now that you understand computers, let’s explore what programming is and how it works.

### ✅ Module 2: Programming Basics

#### 🎯 Learning Goals:

* What is programming?
* How a program runs
* What is Java?
* Introduction to algorithms

#### 🧠 Topics Covered:

1. **What is Programming?**

   * Giving instructions to a computer to perform tasks
2. **Languages & Compilers**

   * High-level vs Low-level languages
3. **Why Java?**

   * Platform independent, object-oriented, widely used
4. **Introduction to Algorithms & Flowcharts**

#### 🛠️ Exercise:

* Write a real-life algorithm (e.g., making tea)
* Draw a flowchart for the same process

#### 💡 Common Mistake:

* Jumping into code without understanding the logic first.

---

## 🧑‍💻 Phase 3: Getting Started with Java

Now that you're ready to program, let’s start coding in Java.

### ✅ Module 3: Java Setup & Hello World

#### 🎯 Learning Goals:

* Set up Java on your system
* Write your first Java program
* Understand how Java code is compiled and run

#### 🧠 Topics Covered:

1. Installing JDK and IntelliJ/VS Code
2. Your first Java Program:

   ```java
   public class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, Tushar!");
       }
   }
   ```
3. Compilation vs Execution
4. Java file structure and conventions

#### 🛠️ Exercise:

* Install Java and write your own `HelloWorld.java`

#### 💡 Common Mistake:

* Forgetting to save the file with `.java` extension or naming mismatch
