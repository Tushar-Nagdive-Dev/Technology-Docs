
## 📘 MODULE 2: Introduction to Programming

---

## 🧠 2.1 What is Programming?

**Programming** is the process of writing **instructions** that a computer can understand and execute to perform specific tasks.

### 🎬 Real-World Analogy:

Think of a computer as a robot. Programming is how you tell the robot **what to do**, step-by-step.

---

## 🧠 2.2 How Programming Works

1. You write code in a **high-level language** (like Java)
2. The **compiler** translates it into machine language (0s and 1s)
3. The **CPU executes** those instructions

---

## 🧠 2.3 What is a Programming Language?

A **programming language** is like a language humans use to communicate — but it’s structured to talk to computers.

### ✅ Types:

| Type                | Example           | Notes                       |
| ------------------- | ----------------- | --------------------------- |
| High-Level Language | Java, Python      | Easy for humans             |
| Low-Level Language  | Assembly, Machine | Close to hardware (complex) |

---

## 🧠 2.4 Why Java?

Java is one of the **most popular and powerful** languages.

### ✅ Key Features:

* **Platform Independent**: Write once, run anywhere (via JVM)
* **Object-Oriented**: Focuses on objects and reusability
* **Secure and Robust**
* Used in: **Android**, web apps, enterprise software, IoT

---

## 🧠 2.5 Algorithms and Flowcharts

Before writing code, we **plan the logic** using:

### 🧮 Algorithm:

A **step-by-step procedure** to solve a problem.

📌 Example: **Making Tea**

1. Boil water
2. Add tea leaves
3. Add sugar
4. Pour into cup

### 🔄 Flowchart:

A **visual diagram** of your logic.

📌 Example:

```plaintext
[Start] → [Boil Water] → [Add Tea Leaves] → [Add Sugar] → [Pour into Cup] → [End]
```

**Q3: Key advantages of Java**  
1. **Platform Independence**: Java code runs on any device with a Java Virtual Machine (JVM), enabling "write once, run anywhere."  
2. **Object-Oriented**: Supports modular, reusable code through concepts like encapsulation, inheritance, and polymorphism.  
3. **Robustness**: Features like automatic memory management (garbage collection) and exception handling reduce errors.  
4. **Security**: Built-in features like bytecode verification and sandboxing enhance secure execution.  
5. **Large Community and Libraries**: Extensive APIs and a vast community provide support and resources for development.
