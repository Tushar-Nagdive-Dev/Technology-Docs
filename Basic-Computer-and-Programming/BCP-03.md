## 🧠 1.1 What Is a Computer?

A **computer** is an electronic device that:

* Takes **input**
* **Processes** it
* Produces **output**
* And can **store data** for later use

### 📊 IPO Model (Input-Process-Output)

This is the foundation of how any computer system works:

| Input      | Process            | Output         |
| ---------- | ------------------ | -------------- |
| Keyboard   | CPU (calculations) | Monitor        |
| Mouse      | Software logic     | Printed result |
| Microphone | Audio processing   | Sound output   |

📌 **Example:**
You press the **"A" key** → The system processes it → The letter **"A"** shows up on screen.

## 🧠 1.2 Hardware vs Software

### 🖥️ Hardware:

Physical components you can **touch**.

| Component | Purpose               |
| --------- | --------------------- |
| CPU       | Brain of the computer |
| RAM       | Temporary memory      |
| Hard Disk | Permanent storage     |
| Keyboard  | Input device          |
| Monitor   | Output device         |

### 💽 Software:

Programs that tell hardware what to do.

| Type            | Examples              |
| --------------- | --------------------- |
| System Software | Windows, Linux, macOS |
| Application SW  | Chrome, MS Word, Java |

> Without software, hardware is just metal and plastic.

## 🧠 1.4 How Data Is Stored

All data is stored as **0s and 1s (binary)**.

### Example:

* `A` = `01000001` (in binary)
* Numbers, images, music—all are stored in binary

### Storage Units:

| Unit | Size              |
| ---- | ----------------- |
| Bit  | Smallest (0 or 1) |
| Byte | 8 bits            |
| KB   | 1024 Bytes        |
| MB   | 1024 KB           |
| GB   | 1024 MB           |

---

## 🧠 1.5 Number Systems

### 🔢 Binary, Decimal, Hexadecimal

| Base | Digits Used | Example         |
| ---- | ----------- | --------------- |
| 2    | 0, 1        | `1010` (Binary) |
| 10   | 0 to 9      | `123` (Decimal) |
| 16   | 0–9 + A–F   | `1F` (Hex)      |

### ✅ Example Conversions:

* Binary `1010` → Decimal `10`
* Decimal `15` → Binary `1111`

**Q2: Convert Decimal 13 to Binary**  
To convert 13 to binary:  
13 ÷ 2 = 6 remainder 1  
6 ÷ 2 = 3 remainder 0  
3 ÷ 2 = 1 remainder 1  
1 ÷ 2 = 0 remainder 1  
Reading remainders bottom-up: **1101**
