## 📌 **Stage 1: Foundational Concepts (Understanding the Core Principles)**  

Before diving into specific design patterns, you need to **understand the fundamental concepts** behind them. 

### 🔹 **1. What are Design Patterns?**
- A **design pattern** is a **reusable solution** to a commonly occurring problem in software design.
- They are not **finished code** but **templates** that guide solutions for software problems.

### 🔹 **2. Categories of Design Patterns**
Design patterns are broadly classified into **three categories**:

| **Category**        | **Purpose** |
|-------------------|-----------|
| **Creational Patterns**  | Handle object creation efficiently. |
| **Structural Patterns**  | Define the structure and composition of objects/classes. |
| **Behavioral Patterns**  | Focus on object interactions and communication. |

### 🔹 **3. SOLID Principles**
Before learning patterns, you **must** understand the **SOLID** principles. These principles **ensure** that your design is **scalable, maintainable, and flexible**.

| **Principle** | **Explanation** |
|--------------|---------------|
| **S**ingle Responsibility Principle (SRP) | A class should have **only one reason to change**. |
| **O**pen/Closed Principle (OCP) | Classes should be **open for extension, but closed for modification**. |
| **L**iskov Substitution Principle (LSP) | Subclasses should **extend** without breaking the parent class behavior. |
| **I**nterface Segregation Principle (ISP) | Interfaces should be **small and specific**, not **fat interfaces**. |
| **D**ependency Inversion Principle (DIP) | High-level modules should not depend on low-level modules directly. |

## 📌 **Stage 2: Intermediate Level – Core Design Patterns**  

Once you grasp the basics, we will dive deep into **actual patterns** grouped by category.

### **1️⃣ Creational Patterns (Handling Object Creation Efficiently)**
These patterns deal with **creating objects** in an optimized way.

✔ **Factory Method**  
✔ **Abstract Factory**  
✔ **Singleton**  
✔ **Prototype**  
✔ **Builder**  

🔍 **Example:** Instead of `new`, we use a **Factory** to create objects dynamically.

### **2️⃣ Structural Patterns (Defining Object Structures)**
These patterns focus on **how objects and classes interact** with each other.

✔ **Adapter**  
✔ **Bridge**  
✔ **Composite**  
✔ **Decorator**  
✔ **Facade**  
✔ **Flyweight**  
✔ **Proxy**  

🔍 **Example:** The **Adapter Pattern** converts one interface into another to make it compatible.

### **3️⃣ Behavioral Patterns (Handling Object Interactions)**
These patterns focus on **communication between objects**.

✔ **Chain of Responsibility**  
✔ **Command**  
✔ **Interpreter**  
✔ **Iterator**  
✔ **Mediator**  
✔ **Memento**  
✔ **Observer**  
✔ **State**  
✔ **Strategy**  
✔ **Template Method**  
✔ **Visitor**  

🔍 **Example:** The **Observer Pattern** is used in Java **Event Listeners**.
