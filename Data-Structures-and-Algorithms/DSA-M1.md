## **1.1 What are Data Structures and Algorithms?**  

### 📘 **Data Structures (DS):**  
- Organized ways to store and manage data for efficient access and modification.  
- Examples: Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, HashMaps.  

### 📘 **Algorithms (Algo):**  
- Step-by-step procedures or formulas to solve problems.  
- Examples: Sorting (Bubble Sort, Quick Sort), Searching (Binary Search), Graph Traversal (DFS, BFS).  

---

## **1.2 Why Learn DSA?**  
- Enhances problem-solving skills.  
- Essential for technical interviews and competitive programming.  
- Used in real-world applications like search engines, social media feeds, and database indexing.

## **1.3 Setting Up Java Development Environment**  

### ⚙️ **Step 1: Install JDK (Java Development Kit)**  
1. Download the latest version of JDK from [Oracle's website](https://www.oracle.com/java/technologies/javase-downloads.html).  
2. Install it and set up the environment variable:
   - **Windows**: Add `C:\Program Files\Java\jdk-x.x.x\bin` to the Path variable.  
   - **Mac/Linux**: Add to `.bash_profile` or `.zshrc`:
     ```bash
     export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-x.x.x/Contents/Home
     export PATH=$JAVA_HOME/bin:$PATH
     ```

### ⚙️ **Step 2: Install an IDE**  
- **IntelliJ IDEA** (Recommended) or **Eclipse**.  
- Download from:
  - [IntelliJ IDEA](https://www.jetbrains.com/idea/download/)  
  - [Eclipse](https://www.eclipse.org/downloads/)  

---

### ⚙️ **Step 3: Verify Installation**  
Open the terminal or command prompt and check Java version:
```bash
java -version
```
Output should be something like:
```
java version "17.0.x"
```

## **1.4 Writing Your First Java Program: "Hello, DSA World!"**  

Let's start with a simple Java program to check your setup.

---

### 📘 **Code: HelloDSA.java**  
```java
public class HelloDSA {
    public static void main(String[] args) {
        System.out.println("Hello, DSA World!");
    }
}
```

---

### ⚙️ **Step to Run the Program:**  
1. Open your terminal or command prompt.  
2. Navigate to the folder where the file is saved.  
3. Compile the program using:  
    ```bash
    javac HelloDSA.java
    ```
4. Run the program using:  
    ```bash
    java HelloDSA
    ```

---

### 📊 **Expected Output:**  
```
Hello, DSA World!
```
