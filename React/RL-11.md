## 📘 Lesson 15: Hooks Deep Dive — `useRef`, `useLayoutEffect`, `useImperativeHandle`, and Custom Hooks

### 🧩 Part 1: `useRef()` – Accessing DOM and Holding Mutable Values

#### 🔍 What is `useRef`?

> `useRef` creates a **reference object** that can hold:

* A **DOM node** reference (like `document.querySelector`)
* A **mutable variable** that **doesn’t cause re-render** when changed

---

### ✅ Basic Example: Access DOM Element

```jsx
import { useRef } from 'react';

function FocusInput() {
  const inputRef = useRef();

  function handleClick() {
    inputRef.current.focus();
  }

  return (
    <div>
      <input ref={inputRef} placeholder="Click button to focus me" />
      <button onClick={handleClick}>Focus</button>
    </div>
  );
}
```

✅ You now control a DOM element **without using `document.getElementById()`** — the React way!

---

### 🧠 Ref as Persistent State (Without Re-render)

```jsx
const renderCount = useRef(0);
renderCount.current++;
```

✅ Great for storing timestamps, counters, or tracking something across renders **without causing re-renders**.

### 🧩 Part 2: `useLayoutEffect()` – Syncing Before Paint

#### 🔍 Difference from `useEffect`

| `useEffect()`                    | `useLayoutEffect()`                     |
| -------------------------------- | --------------------------------------- |
| Runs **after** paint             | Runs **before** paint                   |
| Good for API calls, side effects | Good for layout reads, DOM measurements |
| Doesn’t block paint              | May block paint (used carefully)        |

---

### ✅ When to Use:

* Measuring DOM elements **before paint**
* Scroll position fixes
* Preventing UI flickers/glitches

---

### ✨ Example:

```jsx
import { useLayoutEffect, useRef } from 'react';

function MeasureBox() {
  const boxRef = useRef();

  useLayoutEffect(() => {
    console.log(boxRef.current.getBoundingClientRect());
  }, []);

  return <div ref={boxRef} style={{ width: 300, height: 100, background: 'lightblue' }} />;
}
```

### 🧩 Part 3: `useImperativeHandle()` – Customize `ref` Exposure

#### 🔍 Used with `forwardRef`

> Lets you **expose specific methods** to the parent using `ref`.

---

### ✨ Example:

📄 Child component:

```jsx
import { useImperativeHandle, forwardRef, useRef } from 'react';

const FancyInput = forwardRef((props, ref) => {
  const inputRef = useRef();

  useImperativeHandle(ref, () => ({
    focus: () => inputRef.current.focus()
  }));

  return <input ref={inputRef} />;
});

export default FancyInput;
```

📄 Parent:

```jsx
const inputRef = useRef();

function handleFocus() {
  inputRef.current.focus();
}

<FancyInput ref={inputRef} />
<button onClick={handleFocus}>Focus from Parent</button>
```

✅ This gives the **parent limited access** to **only what you expose**, not the entire DOM.

### 🧩 Part 4: Custom Hooks — Reuse Logic Across Components

#### 🔍 Why Use Custom Hooks?

* Reuse complex stateful logic across components
* Cleaner and more modular code

✅ **Custom hooks always start with `use`**

---

### ✨ Example: useLocalStorage Hook

```jsx
import { useState, useEffect } from 'react';

function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved !== null ? JSON.parse(saved) : initialValue;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}
```

📄 Usage:

```jsx
const [name, setName] = useLocalStorage('name', '');
```

✅ Now `name` is automatically saved in and loaded from localStorage.

---

### 🧠 Summary

| Hook                  | Purpose                                    |
| --------------------- | ------------------------------------------ |
| `useRef`              | Access DOM or persist values               |
| `useLayoutEffect`     | DOM reads before paint                     |
| `useImperativeHandle` | Let parent control child methods via `ref` |
| Custom Hooks          | Reuse stateful logic across components     |
