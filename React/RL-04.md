## 📘 Lesson 8: Forms and Controlled Components in React

---

### 🧩 Part 1: What is a Controlled Component?

#### 🔍 Definition:

> A **controlled component** is a form element (like `<input>`, `<textarea>`, `<select>`) whose value is **controlled by React state**.

React becomes the **single source of truth** for form inputs.

---

### ✅ Basic Example: Controlled Input Field

```jsx
import { useState } from 'react';

function NameForm() {
  const [name, setName] = useState('');

  function handleChange(e) {
    setName(e.target.value);
  }

  function handleSubmit(e) {
    e.preventDefault(); // prevent default page reload
    alert(`Submitted: ${name}`);
  }

  return (
    <form onSubmit={handleSubmit}>
      <label>Enter your name:</label>
      <input type="text" value={name} onChange={handleChange} />
      <button type="submit">Submit</button>
    </form>
  );
}
```

---

### 🧠 Key Concept Breakdown

| Concept         | Purpose                           |
| --------------- | --------------------------------- |
| `useState('')`  | Holds the input value             |
| `onChange`      | Updates state on typing           |
| `value={state}` | Makes the input controlled        |
| `onSubmit`      | Handles the form submission logic |

---

### 🧩 Part 2: Handling Multiple Form Fields

Use a single object in state to handle multiple form fields.

```jsx
function ContactForm() {
  const [formData, setFormData] = useState({
    name: '',
    email: ''
  });

  function handleChange(e) {
    setFormData(prev => ({
      ...prev,
      [e.target.name]: e.target.value
    }));
  }

  function handleSubmit(e) {
    e.preventDefault();
    console.log(formData);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" value={formData.name} onChange={handleChange} placeholder="Name" />
      <input name="email" value={formData.email} onChange={handleChange} placeholder="Email" />
      <button type="submit">Send</button>
    </form>
  );
}
```

✅ You now have a fully working form with **two fields** and **one state object**!

### 🔄 Dynamic Validations (Basic)

```jsx
function ValidatedForm() {
  const [email, setEmail] = useState('');
  const [error, setError] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    if (!email.includes('@')) {
      setError('Invalid email format');
    } else {
      setError('');
      alert('Submitted!');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="Enter email"
      />
      {error && <p style={{ color: 'red' }}>{error}</p>}
      <button type="submit">Submit</button>
    </form>
  );
}
```

---

### ❗ Common Mistakes to Avoid:

| Mistake                                  | Why it's wrong              | Fix                                     |
| ---------------------------------------- | --------------------------- | --------------------------------------- |
| Not using `value` prop                   | Input becomes uncontrolled  | Always bind with state                  |
| Forgetting `e.preventDefault()`          | Page reloads on form submit | Always call it in submit handler        |
| Using multiple `useState` for each input | Not scalable                | Use a single object for multiple fields |

### 🧠 Summary

| Feature              | Key Points                                    |
| -------------------- | --------------------------------------------- |
| Controlled Component | React state drives the input value            |
| `useState`           | Use to manage input values                    |
| `onChange`           | Update state on typing                        |
| `onSubmit`           | Process the form                              |
| Validation           | Use conditions inside handlers or `useEffect` |
