## 📘 Week 1.1 – JSX, Rendering, and Your First React Component

---

### 🔷 1. What is JSX?

JSX stands for **JavaScript XML**. It allows you to write HTML-like syntax inside JavaScript.

#### ✅ JSX Example:

```jsx
const greeting = <h1>Hello, Tushar!</h1>;
```

> Under the hood: `const greeting = React.createElement('h1', null, 'Hello, Tushar!')`

---

### 🔷 2. Rendering JSX in React

You use `ReactDOM.render()` (or the latest `createRoot`) to render components to the DOM.

#### ✅ Example (in `index.js`):

```jsx
import React from 'react';
import ReactDOM from 'react-dom/client';

const root = ReactDOM.createRoot(document.getElementById('root'));

const App = () => {
  return <h1>Hello, Tushar!</h1>;
};

root.render(<App />);
```

---

### 🔷 3. Creating Functional Components

#### ✅ Functional Component:

```jsx
function Welcome() {
  return <h2>Welcome to React!</h2>;
}
```

#### ✅ Arrow Function Version:

```jsx
const Welcome = () => <h2>Welcome to React!</h2>;
```

You can now render `<Welcome />` inside your main `App` component.

---

### 🧠 Expert Insight:

* **JSX is compiled** before execution.
* **Every JSX tag must have a single parent**:
  ❌ Incorrect:

  ```jsx
  return <h1>Hi</h1><h2>There</h2>;
  ```

  ✅ Correct:

  ```jsx
  return (
    <>
      <h1>Hi</h1>
      <h2>There</h2>
    </>
  );
  ```

> This `<>...</>` is called a **React Fragment**.

---

### ⚠️ Common Mistakes:

| Mistake                                     | Correction                                  |
| ------------------------------------------- | ------------------------------------------- |
| Returning multiple root elements            | Wrap them in a `<div>` or `<>...</>`        |
| Forgetting return in arrow functions        | Use `() => <div />` or `{ return <div /> }` |
| Using `class` instead of `className` in JSX | Use `className="box"`                       |

### 🛠️ Mini Project: Create a Welcome Card

```jsx
function WelcomeCard(props) {
  return (
    <div className="card">
      <h2>Hello, {props.name}!</h2>
      <p>You're learning React with Maya 🌟</p>
    </div>
  );
}

function App() {
  return <WelcomeCard name="Tushar" />;
}
```

✅ Add basic CSS to make it nice.
