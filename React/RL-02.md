## 📘 Lesson 6: Props, State, and Event Handling in React

---

### 🧩 Part 1: **Props** – Passing Data to Components

#### 🔍 What are Props?

> **Props** (short for **properties**) are used to pass data **from parent to child** components.

They are **read-only** and cannot be changed by the receiving component.

#### 📦 Example:

```jsx
// Greeting.jsx
function Greeting(props) {
  return <h2>Hello, {props.name}!</h2>;
}

export default Greeting;
```

```jsx
// App.jsx
import Greeting from './components/Greeting';

function App() {
  return (
    <div>
      <Greeting name="Tushar" />
      <Greeting name="Nagdive" />
    </div>
  );
}
```

✅ Output:

```
Hello, Tushar!
Hello, Nagdive!
```

---

### 📌 Notes on Props:

* Props are like **function arguments**.
* You **cannot modify** props inside the child.
* You can pass any data: strings, numbers, objects, arrays, functions.

---

### 🧩 Part 2: **State** – Managing Dynamic Data

#### 🔍 What is State?

> State is like a variable inside your component. It allows your component to **remember and react to data changes**.

#### 🧪 Hook: `useState` (from React)

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count is: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}
```

✅ Output:

```
Count is: 0
[Increment] → 1 → 2 → ...
```

#### 📌 Notes on State:

* You must use the `useState` hook to create state in functional components.
* Never update state **directly** (e.g., `count = 5 ❌`)
* Use the **setter function** returned by `useState`.

### 🧩 Part 3: **Event Handling**

React handles events similarly to HTML but with some syntax changes.

#### HTML Example:

```html
<button onclick="doSomething()">Click</button>
```

#### React Example:

```jsx
<button onClick={handleClick}>Click</button>
```

✅ Event names are in **camelCase**: `onClick`, `onChange`, `onSubmit`, etc.

---

### 💻 Example: Click Handler

```jsx
function Clicker() {
  function handleClick() {
    alert('You clicked me!');
  }

  return <button onClick={handleClick}>Click Me</button>;
}
```

## 🧪 Exercise 2: Create a Dynamic Component

**✅ Task: Build a Like Button**

Create a component that shows:

* “❤️ Likes: X”
* A button to increase the count

```jsx
import { useState } from 'react';

function LikeButton() {
  const [likes, setLikes] = useState(0);

  return (
    <div>
      <h3>❤️ Likes: {likes}</h3>
      <button onClick={() => setLikes(likes + 1)}>Like</button>
    </div>
  );
}

export default LikeButton;
```

Use this in `App.jsx`:

```jsx
import LikeButton from './components/LikeButton';

function App() {
  return (
    <div>
      <LikeButton />
    </div>
  );
}
```

### ❗ Common Mistakes to Avoid

| Mistake                              | Fix                                                          |
| ------------------------------------ | ------------------------------------------------------------ |
| Trying to modify props               | Props are read-only. Use state if you need to change values. |
| Directly modifying state             | ❌ `count++`; ✅ `setCount(count + 1)`                         |
| Forgetting to import `useState`      | Always import it: `import { useState } from 'react';`        |
| Using `class` instead of `className` | React uses `className`                                       |

---

### 🧠 Summary:

| Concept        | Purpose                                        |
| -------------- | ---------------------------------------------- |
| Props          | Send data from parent to child                 |
| State          | Hold internal data that can change             |
| Event Handling | Make UI interactive (click, change, submit...) |
