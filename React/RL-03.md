## 📘 Lesson 7: Conditional Rendering and Lists in React

---

### 🧩 Part 1: **Conditional Rendering**

#### 🔍 What is it?

> Conditional rendering lets you show or hide parts of the UI **based on logic or data**.

---

### ✅ 1. **Using `if` in Component Body**

```jsx
function WelcomeMessage({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h2>Welcome back!</h2>;
  } else {
    return <h2>Please log in.</h2>;
  }
}
```

---

### ✅ 2. **Ternary Operator (Inline)**

```jsx
function UserStatus({ online }) {
  return (
    <p>
      Status: {online ? '🟢 Online' : '🔴 Offline'}
    </p>
  );
}
```

---

### ✅ 3. **Logical AND (`&&`)**

Useful for showing something only if a condition is true.

```jsx
function Notification({ message }) {
  return (
    <>
      {message && <p>📢 {message}</p>}
    </>
  );
}
```

✅ If `message` is empty or `null`, nothing will be rendered.

---

### 🧠 Real-World Example: Toggle Visibility

```jsx
import { useState } from 'react';

function ToggleMessage() {
  const [visible, setVisible] = useState(false);

  return (
    <div>
      <button onClick={() => setVisible(!visible)}>
        {visible ? 'Hide' : 'Show'} Message
      </button>
      {visible && <p>This is a toggled message!</p>}
    </div>
  );
}
```

### 🧩 Part 2: **Rendering Lists in React**

#### 🔍 What is it?

> When you have an array of data (like users or products), you use `.map()` to render each item as a JSX element.

---

### ✅ Example: List of Names

```jsx
const names = ['Tushar', 'Nagdive', 'React Learner'];

function NameList() {
  return (
    <ul>
      {names.map((name, index) => (
        <li key={index}>👤 {name}</li>
      ))}
    </ul>
  );
}
```

✅ `key` prop is important — React uses it to identify each item uniquely for updates.

---

### 🧠 Real-World Example: List of Users

```jsx
const users = [
  { id: 1, name: 'Tushar', role: 'Admin' },
  { id: 2, name: 'Anjali', role: 'User' },
  { id: 3, name: 'Ravi', role: 'Editor' }
];

function UserList() {
  return (
    <div>
      <h3>👥 Users:</h3>
      <ul>
        {users.map(user => (
          <li key={user.id}>
            {user.name} — <strong>{user.role}</strong>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

---

### ❗ Common Mistakes to Avoid:

| Mistake                          | Why it’s a problem                       | Fix                                       |
| -------------------------------- | ---------------------------------------- | ----------------------------------------- |
| Missing `key` in list items      | Causes rendering issues                  | Add a `unique key` like `user.id`         |
| Using `index` as key             | Bad for dynamic lists (e.g., reordering) | Use unique ID instead                     |
| Writing `if` inside JSX directly | JSX is an expression                     | Use ternary `? :` or move logic above JSX |

### 🧪 Exercise 3: List + Toggle Combo

✅ **Task: Build a component that displays a list of books and can hide/show them with a button**

```jsx
import { useState } from 'react';

const books = [
  'Clean Code',
  'The Pragmatic Programmer',
  'JavaScript: The Good Parts'
];

function BookList() {
  const [show, setShow] = useState(true);

  return (
    <div>
      <button onClick={() => setShow(!show)}>
        {show ? 'Hide' : 'Show'} Books
      </button>

      {show && (
        <ul>
          {books.map((book, index) => (
            <li key={index}>📚 {book}</li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

---

### 📌 Summary

| Concept               | Usage                            |
| --------------------- | -------------------------------- |
| Conditional Rendering | Show/hide content based on logic |
| `if` / `else`         | Inside function body             |
| `? :` (Ternary)       | Inline conditional               |
| `&&` (Short circuit)  | Render only if condition is true |
| Lists with `.map()`   | Render arrays of JSX             |
| `key` prop            | Must be unique per list item     |
