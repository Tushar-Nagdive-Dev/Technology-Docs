## 📚 Phase 1: React Foundations (Beginner Level)

### ✅ Goal:

Understand what React is, why it's used, how it works at the core level, and how to build your first React application.

---

### 📘 Lesson 1: What is React?

#### 🔍 Concept:

React is a **JavaScript library** created by **Facebook** for building **user interfaces (UI)**. It’s **component-based**, **declarative**, and **fast**.

#### 🔑 Key Features:

| Feature                  | Meaning                                               |
| ------------------------ | ----------------------------------------------------- |
| Component-based          | UI is split into reusable pieces                      |
| Declarative              | You describe how the UI should look for a given state |
| Virtual DOM              | Efficient UI updates using a virtual copy of the DOM  |
| JSX                      | HTML + JS syntax inside JavaScript                    |
| Unidirectional Data Flow | Data flows from parent → child                        |

#### 💡 Real-World Use Cases:

* Web apps like Instagram, WhatsApp Web, Facebook
* Admin dashboards, analytics platforms
* Ecommerce product UI, dynamic search/filter interfaces

### 🛠️ Lesson 2: Setting Up the Environment

#### ✅ Prerequisites:

* Node.js (Install from [https://nodejs.org/](https://nodejs.org/))
* A code editor like **Visual Studio Code**

#### 🧪 Installation Steps:

```bash
# Create a new React app using Vite (modern and fast)
npm create vite@latest my-react-app --template react

# Move into the app folder
cd my-react-app

# Install dependencies
npm install

# Start development server
npm run dev
```

✅ Visit `http://localhost:5173` — You’ll see the Vite + React page running.

### 🧠 Lesson 3: Understanding JSX

#### 🔍 What is JSX?

JSX stands for **JavaScript XML**. It lets you write HTML inside JavaScript.

#### Example:

```jsx
const element = <h1>Hello, React!</h1>;
```

Under the hood, it's compiled to:

```js
const element = React.createElement('h1', null, 'Hello, React!');
```

✅ JSX makes your code cleaner and easier to visualize.

#### ❗ Common Mistakes:

* Forgetting to close tags (`<img> → <img />`)
* Using `class` instead of `className`
* Only returning one root element from a component

### 🧱 Lesson 4: Components in React

#### 📦 Two Types of Components:

1. **Function Component (modern and preferred):**

```jsx
function Welcome() {
  return <h2>Welcome to React!</h2>;
}
```

2. **Class Component (older):**

```jsx
class Welcome extends React.Component {
  render() {
    return <h2>Welcome to React!</h2>;
  }
}
```

### 🧪 Exercise 1: Build Your First Component

1. Inside `src/components/Hello.jsx`

```jsx
function Hello() {
  return <h3>Hello from your first component!</h3>;
}

export default Hello;
```

2. Use it inside `App.jsx`

```jsx
import Hello from './components/Hello';

function App() {
  return (
    <div>
      <h1>React Starter</h1>
      <Hello />
    </div>
  );
}
```

✅ You’ve just created and rendered your first React component!

---

### 📝 Notes for Mastery:

* ✅ **React is not a framework** like Angular or Vue. It's just a UI library.
* ✅ Keep components small and reusable.
* ⚠️ Don’t forget to export and import components.
* ⚠️ Each component must return **one root JSX element**.
