## 🧭 **Phase 1: Foundational React – The Basics**

### 🔹 Week 1: Introduction to React

#### ✅ Goals:

* Understand what React is and why it's popular.
* Learn the core philosophy: Component-based architecture.

#### 📘 Topics Covered:

1. **What is React?**

   * History & purpose
   * React vs traditional DOM
2. **Key Concepts**

   * JSX
   * Virtual DOM
   * Components (Functional vs Class)

#### 🛠️ Real-World Example:

* Create a basic webpage with “Hello, Tushar!” using React.

#### 🧠 Expert Insight:

> “JSX is not HTML – it's syntactic sugar for `React.createElement`. Always keep that in mind.”

#### ⚠️ Common Mistakes to Avoid:

* Confusing JSX with plain HTML.
* Forgetting to import `React` in older setups.

#### 🏋️‍♂️ Exercise:

* Install Node.js and create your first React app using:

  ```bash
  npx create-react-app react-foundations
  cd react-foundations
  npm start
  ```

#### 📚 Resources:

* [React Official Docs - Getting Started](https://reactjs.org/docs/getting-started.html)
* [JSX Deep Dive (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/JSX)
