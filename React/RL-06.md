## 📘 Lesson 10: React Router – Navigation in Single Page Applications (SPA)

---

### 🧩 Part 1: What is React Router?

#### 🔍 Definition:

> **React Router** is a library that enables **client-side routing** in React applications.

It allows you to:

* Create different "pages" or "views" in one React app
* Navigate between pages **without reloading the page**
* Pass route parameters like `/users/123`

---

### ✅ Why It Matters

| Feature             | Benefit                                    |
| ------------------- | ------------------------------------------ |
| No full page reload | Faster user experience                     |
| Dynamic routing     | URLs based on app state                    |
| Nested routing      | Create layouts and sub-pages easily        |
| Route params        | Fetch data based on URL (e.g. `/user/:id`) |

---

### 🧩 Part 3: Basic Setup

Let’s create a small website with 3 pages: Home, About, and Contact.

---

#### 🗂 Folder Structure:

```
src/
├── App.jsx
├── main.jsx
├── pages/
│   ├── Home.jsx
│   ├── About.jsx
│   └── Contact.jsx
```

---

#### 📄 pages/Home.jsx

```jsx
export default function Home() {
  return <h2>🏠 Home Page</h2>;
}
```

#### 📄 pages/About.jsx

```jsx
export default function About() {
  return <h2>ℹ️ About Us</h2>;
}
```

#### 📄 pages/Contact.jsx

```jsx
export default function Contact() {
  return <h2>📞 Contact Page</h2>;
}
```

---

#### 📄 App.jsx – Set up Router

```jsx
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';
import Contact from './pages/Contact';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link> |{' '}
        <Link to="/about">About</Link> |{' '}
        <Link to="/contact">Contact</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;
```

✅ Now you can navigate between `/`, `/about`, and `/contact` — no page reloads!

---

### 🧠 Part 4: Route Parameters

```jsx
<Route path="/user/:id" element={<User />} />
```

#### 📄 User.jsx

```jsx
import { useParams } from 'react-router-dom';

export default function User() {
  const { id } = useParams();
  return <h2>User ID: {id}</h2>;
}
```

Visiting `/user/42` will display:

```
User ID: 42
```

### ❗ Common Mistakes to Avoid:

| Mistake                                               | Fix                     |                             |
| ----------------------------------------------------- | ----------------------- | --------------------------- |
| Using `href` instead of `Link`                        | Causes full page reload | Use `<Link to="/about" />`  |
| Missing `<BrowserRouter>`                             | Routes won’t work       | Wrap everything inside it   |
| Forgetting to use `element={<Component />}` in routes | Causes error            | Must wrap components in JSX |

---

### 📌 Summary

| Concept        | Example                                       |
| -------------- | --------------------------------------------- |
| Navigate       | `<Link to="/about" />`                        |
| Define routes  | `<Route path="/about" element={<About />} />` |
| Get URL param  | `useParams()`                                 |
| SPA navigation | No full reload                                |
