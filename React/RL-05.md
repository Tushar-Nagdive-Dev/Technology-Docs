## 📘 Lesson 9: React Lifecycle and the `useEffect` Hook

---

### 🧩 Part 1: Understanding the React Lifecycle

#### 🔍 What is a Lifecycle?

> A **lifecycle** is the series of phases a React component goes through:

1. **Mounting** – when the component is created and inserted into the DOM.
2. **Updating** – when the component re-renders due to state/prop changes.
3. **Unmounting** – when the component is removed from the DOM.

---

### ✅ Functional Components Lifecycle (via Hooks)

React handles lifecycle in functional components using the `useEffect()` hook — it's the **side-effect manager**.

---

### 🧩 Part 2: What is `useEffect()`?

#### 🔍 Purpose:

> `useEffect()` is used to run **side effects** in React — like:

* Fetching data from an API
* Subscribing to events
* Updating the DOM manually
* Setting timers
* Logging on mount/update/unmount

---

### ✅ Basic Syntax

```jsx
import { useEffect } from 'react';

useEffect(() => {
  // code to run (side effect)
}, []);
```

#### 📘 Breakdown:

| Part       | Meaning                                   |
| ---------- | ----------------------------------------- |
| `() => {}` | The effect function to run                |
| `[]`       | Dependency array controlling when it runs |

---

### 🧪 Example 1: Run on Mount (Component Did Mount)

```jsx
import { useEffect } from 'react';

function Welcome() {
  useEffect(() => {
    console.log("Component mounted!");
  }, []); // empty array = run only once

  return <h1>Hello, React!</h1>;
}
```

---

### 🧪 Example 2: Run on State Change (Component Did Update)

```jsx
import { useEffect, useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log(`Count changed: ${count}`);
  }, [count]); // only runs when `count` changes

  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  );
}
```

---

### 🧪 Example 3: Cleanup Function (Component Will Unmount)

```jsx
useEffect(() => {
  const timer = setInterval(() => {
    console.log('Tick');
  }, 1000);

  return () => {
    clearInterval(timer); // cleanup
    console.log('Timer stopped');
  };
}, []);
```

✅ Cleanup runs when component **unmounts** or before re-running the effect.

---

### 🔁 Real Use Case: Fetching Data

```jsx
import { useEffect, useState } from 'react';

function PostList() {
  const [posts, setPosts] = useState([]);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/posts?_limit=5')
      .then(res => res.json())
      .then(data => setPosts(data));
  }, []); // run once

  return (
    <ul>
      {posts.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
}
```

---

### ❗ Common Mistakes to Avoid

| Mistake                                 | Fix                                  |
| --------------------------------------- | ------------------------------------ |
| Forgetting dependency array             | Effect runs on every render 😱       |
| Modifying state without dependencies    | Causes infinite loop                 |
| Not cleaning up                         | Causes memory leaks in timers/events |
| Using async directly inside `useEffect` | Use IIFE or separate function        |

```jsx
useEffect(() => {
  async function fetchData() {
    const res = await fetch(...);
    // ...
  }
  fetchData();
}, []);
```

---

### 📌 Summary

| Pattern                         | Behavior                                      |
| ------------------------------- | --------------------------------------------- |
| `useEffect(() => {}, [])`       | Run once on mount                             |
| `useEffect(() => {}, [count])`  | Run when `count` changes                      |
| `return () => {}` inside effect | Run cleanup before unmount or next effect run |
