## 📘 Lesson 11: Component Composition, Props Drilling, and React Context API

---

### 🧩 Part 1: Component Composition – Thinking in Components

#### 🔍 What is it?

> **Component Composition** means building your UI from **small, reusable building blocks**.

Each component should:

* Have **one responsibility**
* Be **reusable**
* Be **composed** inside bigger components

#### ✅ Example:

```jsx
function Avatar({ name }) {
  return <img src={`https://robohash.org/${name}`} alt={name} />;
}

function UserProfile({ name }) {
  return (
    <div>
      <Avatar name={name} />
      <p>{name}</p>
    </div>
  );
}

function App() {
  return <UserProfile name="Tushar" />;
}
```

🧠 This is composition: small components (like `Avatar`) used inside larger ones (like `UserProfile`).

---

### 🧩 Part 2: Props Drilling

#### 🔍 What is Props Drilling?

> Passing data **through multiple intermediate components** that don’t use it themselves — just to reach a deeply nested child.

#### ❗ Problem:

```jsx
<App>
  <Parent>
    <Child>
      <GrandChild user={user} />
    </Child>
  </Parent>
</App>
```

Even if only `GrandChild` needs `user`, you still pass it through `Parent` and `Child`.

---

### 🧠 When Props Drilling Becomes a Problem:

* Data has to travel too many levels deep
* Unrelated components must accept props
* Makes the code harder to maintain

✅ **Solution**: Use **React Context API**

---

## 🌐 Part 3: React Context API — Share Data Without Props

### 🔍 What is Context?

> A way to **share data globally** between components **without props**.

Common use cases:

* Current logged-in user
* Theme
* Language (i18n)
* Auth token

---

### ✅ Step-by-Step: Create and Use Context

---

### 🧪 Step 1: Create a Context

```jsx
import { createContext } from 'react';

export const UserContext = createContext();
```

---

### 🧪 Step 2: Wrap your app with Provider

```jsx
import { UserContext } from './UserContext';

function App() {
  const user = { name: 'Tushar', role: 'Admin' };

  return (
    <UserContext.Provider value={user}>
      <Dashboard />
    </UserContext.Provider>
  );
}
```

---

### 🧪 Step 3: Consume Context in a deeply nested child

```jsx
import { useContext } from 'react';
import { UserContext } from '../UserContext';

function UserBadge() {
  const user = useContext(UserContext);

  return <p>👋 Welcome, {user.name} ({user.role})</p>;
}
```

✅ No more props drilling — any component can access the context directly!

---

### 🧠 Bonus: Create Your Own Custom Context Hook

```jsx
export function useUser() {
  return useContext(UserContext);
}
```

Then inside any component:

```jsx
const user = useUser();
```

---

### ❗ Common Mistakes to Avoid

| Mistake                            | Fix                                   |                                                |
| ---------------------------------- | ------------------------------------- | ---------------------------------------------- |
| Not wrapping with `Provider`       | Context will be undefined             | Always wrap at root level                      |
| Using context in non-children      | Component must be within `<Provider>` |                                                |
| Forgetting to memoize large values | May cause re-renders                  | Use `useMemo` if context holds complex objects |

---

### 📌 Summary

| Concept               | Description                                 |
| --------------------- | ------------------------------------------- |
| Component Composition | Build UIs from smaller blocks               |
| Props Drilling        | Problem of passing data through many layers |
| Context API           | Global data without props                   |
| `createContext()`     | Create a context                            |
| `useContext()`        | Consume it inside any component             |
| `Provider`            | Supplies the context value                  |
