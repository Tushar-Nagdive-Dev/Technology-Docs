HTTP Status Codes

The 5 Categories of Internet Communication

The "Cheat Sheet" Analogy: Imagine you are at a restaurant talking to a waiter.
1xx: "Hold on, I'm thinking."
2xx: "Here is your food!"
3xx: "You need to go to a different table."
4xx: "You ordered something that isn't on the menu. Your fault."
5xx: "The kitchen is on fire. My fault."

1xx: Informational

Meaning: "Message received, continuing process."

These are temporary responses. The server is saying it has received the start of the request and the client should keep sending the rest of it, or wait for the final response.

100 Continue
The server has received the request headers and the client should proceed to send the request body.
Minute Detail: This is a bandwidth optimization. If you are uploading a massive 5GB video, your browser sends a quick "Can I send this?" header first. If the server says "100 Continue," the browser sends the heavy file. If the server says "401 Unauthorized," the browser saves bandwidth by never sending the 5GB file.
101 Switching Protocols
The server agrees to change the communication protocol.
Minute Detail: Most commonly seen when upgrading a standard HTTP connection into a real-time WebSocket connection for things like live chat apps.

2xx: Success

Meaning: "The action was successfully received, understood, and accepted."

This is what you always want to see. Everything went exactly as planned.

200 OK
The standard success code. The requested data is enclosed in the response.
201 Created
The request was successful, and a new resource was created as a result.
Minute Detail: Typically returned after a successful `POST` request (like registering a new user account or uploading a photo).
204 No Content
The server successfully processed the request, but is not returning any content.
Minute Detail: Common with `DELETE` requests. You asked to delete a record. The server deleted it, so it replies "Success, but I have no data to send back to you."

3xx: Redirection

Meaning: "Further action must be taken to complete the request."

The resource you are looking for is somewhere else. Your browser usually handles these automatically by following the new URL provided by the server.

301 Moved Permanently
The URL has been permanently moved to a new location.
Minute Detail: Crucial for SEO. If you change your website URL from `old-page.html` to `new-page.html`, a 301 tells Google to transfer all the search engine ranking power to the new URL. Browser caching also remembers this permanently.
302 Found (Temporary Redirect)
The URL is temporarily moved.
Minute Detail: Used when doing website maintenance or A/B testing. It tells Google: "Go here for now, but don't update your index because I'll bring the original URL back soon."
304 Not Modified
Tells the client that the requested file hasn't changed since the last time they downloaded it.
Minute Detail: A vital performance trick! The browser loads the image/CSS file from its local cache instead of downloading it again, saving massive amounts of bandwidth.

4xx: Client Error

Meaning: "You messed up. The request contains bad syntax or cannot be fulfilled."

This category means the fault lies with the person or application making the request (the frontend/browser).

400 Bad Request
The server cannot understand the request due to malformed syntax (e.g., missing a required parameter or sending invalid JSON).
401 Unauthorized
Authentication is required and has failed or has not yet been provided.
Minute Detail: Despite the name "Unauthorized," this actually means "Unauthenticated." It means the server is saying: "I don't know who you are. Please log in."
403 Forbidden
The client does not have access rights to the content.
Minute Detail: This is the true "Unauthorized." The server knows exactly who you are (you are logged in), but you are just a regular user trying to access an Admin-only page.
404 Not Found
The server cannot find the requested resource (the URL is broken or the data was deleted).
429 Too Many Requests
The user has sent too many requests in a given amount of time (Rate Limiting).
Minute Detail: Used to prevent DDoS attacks or stop an API from being overwhelmed by a bot.

5xx: Server Error

Meaning: "I messed up. The server failed to fulfill an apparently valid request."

Your request was perfect, but the backend server crashed, timed out, or has a bug in its code.

500 Internal Server Error
A generic error message, given when an unexpected condition was encountered (usually a NullPointerException or unhandled bug in the backend code).
502 Bad Gateway
The server was acting as a gateway or proxy and received an invalid response from the upstream server.
Minute Detail: Imagine your request goes to a Load Balancer (Nginx), which forwards it to your Spring Boot app. If the Spring Boot app is dead/crashed, Nginx sends a 502 Bad Gateway back to the user.
503 Service Unavailable
The server is not ready to handle the request (usually down for maintenance or heavily overloaded).
504 Gateway Timeout
The server acting as a gateway did not get a response in time from the upstream server.
Minute Detail: The upstream server isn't dead (like in 502), it's just taking WAY too long to respond (e.g., stuck on a 5-minute database query), so the proxy gives up and cuts the connection.
