HTTP Status Code Master List

The exhaustive, no-miss dictionary of every standard status code.

1xx: Informational (Hold on, I'm processing...)

CodeTitleSimple Explanation
100ContinueThe server got the initial part of the request. Please send the rest.
101Switching ProtocolsThe server agrees to switch protocols (e.g., from HTTP to WebSockets).
102Processing (WebDAV)The server is processing a large request, but no response is available yet. Prevents timeouts.
103Early HintsLets the browser start pre-loading resources (like CSS/JS) while the server prepares the final response.

2xx: Success (Here is your data!)

CodeTitleSimple Explanation
200OKStandard success. Everything worked perfectly.
201CreatedSuccess, and a new record/resource was created (common for POST).
202AcceptedThe request was accepted, but the server is still working on it in the background.
203Non-Authoritative InfoSuccess, but the data is being returned by a proxy/cache, not the original server.
204No ContentSuccess, but there is absolutely no data to return (common for DELETE).
205Reset ContentSuccess. The server tells the browser to clear the form the user just filled out.
206Partial ContentSuccess, but returning only a chunk of the data (used for resuming paused video downloads).
207Multi-Status (WebDAV)Returns multiple status codes for multiple different operations at once inside an XML message.
208Already ReportedUsed to avoid sending the same data twice in a 207 Multi-Status response.
226IM UsedThe server has fulfilled a GET request for the resource, and the response is a representation of the result of one or more instance-manipulations applied to the current instance.

3xx: Redirection (Go look over there)

CodeTitleSimple Explanation
300Multiple ChoicesThere are multiple options for the resource (e.g., a video in MP4, WebM, or OGG). The user must choose.
301Moved PermanentlyThis URL is dead. The new permanent URL is provided. Update your bookmarks.
302FoundTemporary redirect. Go to this new URL for now, but don't forget the old one.
303See OtherForces a GET request to the new URL (often used after a successful POST to prevent double-submitting forms).
304Not ModifiedNothing changed since your last visit. Just use the copy saved in your browser cache.
305Use ProxyDeprecated. You must use a proxy to access this requested resource.
306Switch ProxyNo longer used. Originally meant "subsequent requests should use the specified proxy."
307Temporary RedirectLike 302, but strictly forbids the browser from changing the HTTP method (a POST must stay a POST).
308Permanent RedirectLike 301, but strictly forbids changing the HTTP method (a POST must stay a POST).

4xx: Client Error (You messed up)

CodeTitleSimple Explanation
400Bad RequestMalformed syntax. The server literally cannot understand what you sent.
401UnauthorizedYou must log in to see this. (Actually means "Unauthenticated").
402Payment RequiredReserved for future use. (Originally intended for digital cash systems).
403ForbiddenYou are logged in, but you don't have admin privileges to see this.
404Not FoundThe classic dead link. The resource does not exist.
405Method Not AllowedYou tried to use POST on a URL that only accepts GET.
406Not AcceptableThe server cannot provide data in the format you requested (e.g., you asked for XML, it only has JSON).
407Proxy Auth RequiredLike 401, but you must authenticate with the proxy server first.
408Request TimeoutYou took too long to send your request. The server closed the connection.
409ConflictYour request conflicts with the server's current state (e.g., trying to create a username that already exists).
410GoneLike a 404, but implies the resource used to exist, but was intentionally and permanently deleted.
411Length RequiredYou forgot to include the `Content-Length` header in your request.
412Precondition FailedYou set certain conditions in your headers, and the server did not meet them.
413Payload Too LargeThe file or data you tried to upload is too big for the server to process.
414URI Too LongThe URL you requested is too long (usually happens when putting too much data in a GET query string).
415Unsupported Media TypeYou sent data in a format the server doesn't support (e.g., sending an image when it wants text).
416Range Not SatisfiableYou asked for a portion of a file that doesn't exist (e.g., asking for byte 1000 of a 500-byte file).
417Expectation FailedThe server cannot meet the requirements of the `Expect` request-header field.
418I'm a teapotAn April Fools' joke from 1998 (RFC 2324). Returned by teapots requested to brew coffee.
421Misdirected RequestThe request was directed at a server that is not configured to produce a response.
422Unprocessable EntityThe syntax was correct, but the data inside was semantically invalid (e.g., negative age).
423Locked (WebDAV)The file or resource you are trying to access is locked.
424Failed DependencyThe request failed because it depended on another request that failed.
425Too EarlyThe server is unwilling to risk processing a request that might be replayed (security feature).
426Upgrade RequiredThe server refuses to perform the request using the current protocol, but might if the client upgrades.
428Precondition RequiredThe server requires the request to be conditional (prevents the "lost update" problem in databases).
429Too Many RequestsRate limiting. You are spamming the server. Slow down.
431Header Fields Too LargeThe server refuses to process the request because the HTTP headers are too large.
451Unavailable For Legal ReasonsCensorship. The server is denying access due to a legal demand (e.g., a court order or government block).

5xx: Server Error (The server messed up)

CodeTitleSimple Explanation
500Internal Server ErrorThe backend code crashed or encountered a bug it didn't know how to handle.
501Not ImplementedThe server does not support the functionality required to fulfill the request.
502Bad GatewayThe proxy server (like a load balancer) received an invalid response from the upstream server.
503Service UnavailableThe server is down for maintenance or completely overloaded and cannot handle the request.
504Gateway TimeoutThe proxy server gave up waiting for the slow upstream server to reply.
505HTTP Version Not SupportedThe HTTP protocol version used in the request is not supported by the server.
506Variant Also NegotiatesInternal configuration error causing a circular reference in content negotiation.
507Insufficient StorageThe server has run out of disk space or memory to process the request.
508Loop Detected (WebDAV)The server detected an infinite loop while processing the request.
510Not ExtendedFurther extensions to the request are required for the server to fulfill it.
511Network Auth RequiredYou need to authenticate to gain network access (like accepting terms on a public airport Wi-Fi).
