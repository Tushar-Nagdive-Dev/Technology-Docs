Spring Boot Property Resolution

The Hierarchy of Configuration (Highest to Lowest Precedence)

1
Command Line Arguments
--server.port=8080
2
Java System Properties
-Dserver.port=8080
3
OS Environment Variables
SERVER_PORT=8080
4
Profile Properties (Outside Jar)
/config/application-prod.yml
5
Profile Properties (Inside Jar)
src/main/resources/application-prod.yml
6
Standard Properties (Outside Jar)
/config/application.yml
7
Standard Properties (Inside Jar)
src/main/resources/application.yml
8
@PropertySource Annotations
@PropertySource("classpath:custom.properties")
9
Default Properties
SpringApplication.setDefaultProperties

💡 How to read this:

If you set `server.port=8080` in your application.yml (Layer 7), but your DevOps team sets an Environment Variable `SERVER_PORT=9090` (Layer 3), your application will start on port 9090 because Layer 3 is higher up the pyramid and overrides Layer 7.
