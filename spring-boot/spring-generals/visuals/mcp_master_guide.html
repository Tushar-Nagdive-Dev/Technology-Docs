Master Guide: Spring Boot + MCP Integration

1. The Big Picture Architecture

📱 Frontend UI

User types: "Add 3 apples to my cart"

HTTP POST

🧠 AI Host (Spring Boot)

Talks to LLM & holds the MCP Bridge

JSON-RPC

🛠️ MCP Server (Spring Boot)

Executes actual Java code & DB logic

2. The End-to-End Data Flow

  1. User Action: User types a prompt in the UI and hits send.
  2. To the Brain: The UI sends the text to the AI Host Server.
  3. Evaluation: The AI Host asks the LLM what to do. The LLM realizes it needs to use the `addToCart` tool.
  4. The Bridge: The AI Host pauses, formats a JSON-RPC request, and sends it across the MCP connection to the MCP Server.
  5. Execution: The MCP Server receives the JSON, triggers the annotated Java method, and saves to the database.
  6. Return Trip: The MCP Server sends a "Success" JSON response back across the bridge.
  7. Synthesis: The LLM reads the success message and generates a friendly text response ("I've added the apples!").
  8. Final Delivery: The AI Host sends this text back to the UI to display to the user.

async function sendToAI() { const userText = document.getElementById("userInput").value; // Send message to our Spring Boot AI API const response = await fetch('http://localhost:8080/api/chat', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ message: userText }) }); // Display the final AI response const finalAnswer = await response.text(); document.getElementById("chatBox").innerText = finalAnswer; }
2. AiChatController.java (The AI Host - Port 8080)
import org.springframework.ai.chat.client.ChatClient; import org.springframework.ai.mcp.client.McpSyncClient; import org.springframework.web.bind.annotation.*; @RestController @RequestMapping("/api") public class AiChatController { private final ChatClient chatClient; public AiChatController(ChatClient.Builder builder, McpSyncClient mcpClient) { // Give the AI access to the MCP Tools menu! this.chatClient = builder .defaultFunctions(mcpClient.listTools()) .build(); } @PostMapping("/chat") public String chatWithUser(@RequestBody ChatRequest request) { // Spring AI handles the prompt, pausing, tool calling, and resuming automatically! return this.chatClient.prompt() .user(request.message()) .call() .content(); } }
3. ShoppingCartService.java (The MCP Server - Port 9090)
import org.springframework.ai.mcp.server.annotation.McpTool; import org.springframework.ai.mcp.server.annotation.McpToolParam; import org.springframework.stereotype.Service; @Service public class ShoppingCartService { // This annotation exposes this method to the AI via MCP @McpTool(description = "Adds an item to the user's shopping cart") public String addToCart( @McpToolParam(description = "The item name") String item, @McpToolParam(description = "How many to add") int quantity) { // Real business logic / database saving goes here System.out.println("Saving " + quantity + " " + item + " to DB..."); return "SUCCESS: Added " + quantity + " " + item + " to the cart."; } }
