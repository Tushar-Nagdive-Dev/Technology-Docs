Jayway JsonPath Cheat Sheet

1. Core Syntax (The Path)

OperatorDescription
$The root element to start the query.
@The current node being processed (used in filters).
*Wildcard. Returns all elements regardless of their names.
..Deep scan. Searches for a key anywhere down the tree.
.<name>Child operator. (e.g., $.store)
[<number>]Array index. (e.g., $.book[2])
[start:end]Array slice operator. (e.g., $.book[0:2])
[?(<expression>)]Filter expression to match specific criteria.

2. Useful Filter Examples

Filter PathWhat it does
$.store.book[?(@.price < 10)]Books where the price is less than 10.
$.store.book[?(@.author == 'Nigel')]Books written by exactly 'Nigel'.
$.store.book[?(@.title =~ /.*Sword.*/i)]Regex: Books with 'Sword' in title (case insensitive).
$.store.book[?(@.isbn)]Books that possess the 'isbn' key (regardless of value).
$..book[?(@.price < 10 && @.category == 'fiction')]Multiple conditions using AND.

3. Java API Operations (DocumentContext)

read(path)

Extracts data based on the path.

String name = ctx.read("$.user.name");

set(path, newValue)

Updates an existing value.

ctx.set("$.user.age", 30);

put(path, key, value)

Adds a new key-value to an Object.

ctx.put("$.user", "status", "active");

add(path, value)

Appends a new element to an Array.

ctx.add("$.user.roles", "ADMIN");

delete(path)

Removes the node entirely.

ctx.delete("$.user.password");
