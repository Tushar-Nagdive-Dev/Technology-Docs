A deep dive into how data travels from your database to your users.

1. Offset-based (The "Skip" Method)

The client asks for a specific "page" by telling the server how many items to skip.

Client
GET /items?offset=20&limit=10
Server
SELECT...OFFSET 20

2. Keyset (The "Tiebreaker" Method)

Instead of skipping, the client says "Give me the next batch starting after this ID."

Client
GET /items?after_id=450
Server
WHERE id > 450
Database

Database View: The DB uses an Index to jump straight to the correct row. No skipping required!

3. Cursor-Based (The "Token" Method)

The server sends an opaque string (the cursor). The client doesn't know what's in it; they just send it back to get the next set.

Client
GET ?cursor=Y3Vyc29yXzEw
Server
Decodes Token -> ID: 450
