What is an Array?

Imagine a row of post office boxes. They are all attached to each other, they are the same size, and they each have a number on the door.

The Golden Rules:

  • One Type Only: If the boxes are for letters (Strings), you can't put packages (Integers) in them.
  • Fixed Size: Once you build the row of boxes, you can't add more boxes later.
  • Start at Zero: The first box is numbered 0, not 1!

Click on the functions below to reveal what they do in simple terms.

Arrays.toString() 👀

What it does: Lets you actually read what is inside the array.

Why you need it: If you try to print an array normally like System.out.println(myArray), Java just prints a random memory address like [I@1b28cdfa. Using Arrays.toString(myArray) prints it beautifully like [10, 20, 30].

Arrays.sort() 📈

What it does: Arranges everything in order automatically.

Why you need it: If your array is [5, 1, 9, 2], running Arrays.sort() instantly changes it to [1, 2, 5, 9]. It works for alphabetical words too!

Arrays.fill() 🎨

What it does: Fills every single slot with the exact same value.

Why you need it: If you have an empty array of 100 slots and want them all to be the number '7', you don't have to write it 100 times. Just use Arrays.fill(myArray, 7).

myArray.length 📏 (Property)

What it does: Tells you exactly how many slots are in the array.

Why you need it: It's crucial for loops! Notice there are no parentheses () at the end. It's a property built right into the array, not an external tool.
