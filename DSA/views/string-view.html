Interactive String Algorithms

Step through MAANG patterns visually to understand exactly how the pointers and memory behave during execution.

Pattern 1: Two Pointers (Valid Palindrome)

Instead of creating a reversed copy of the string (which takes extra memory), we place one pointer at the start and one at the end. We move them toward the center, comparing characters.

Click 'Step Forward' to initialize pointers.

Pattern 2: Sliding Window (Longest Unique Substring)

We use a dynamically resizing "window" to explore the string. The right pointer expands the window to add characters. If we hit a duplicate, the left pointer shrinks the window until the duplicate is gone.

Click 'Step Forward' to start expanding the window.
